# Sprint 0 · 可信基线（第一切片）

日期：2026-09-05  
状态：已完成

## 本轮目标

为长期进化路线建立可重复的应用级回归基线，优先保护真实对话、人格和关系数据不被测试触碰。

## 交付

- 引入 Playwright，并提供 `npm run test:e2e`。
- 新增 5 条 Chromium 端到端关键路径：应用启动、SSE 对话渲染、共同活动面板、人格卡导入/激活、共读书签与讨论草稿回填。
- E2E 后端启动时强制使用系统临时目录作为 `TZTUZHAN_DATA_DIR`，关闭新记忆引擎；对话测试拦截 `/api/chat` 返回确定性 SSE，因此不会调用真实模型或消耗额度。
- 将测试结果、M0 剩余项同步到长期技术路线、进化路线与交接文档。
- 为 `bot.db`、`sessions.db`、`agent_tasks.db` 建立 schema 版本。旧库升级前使用 SQLite 在线备份生成一致快照并执行完整性校验；全部迁移成功后才写版本。
- 提供保守离线恢复函数：仅允许恢复到不存在的新路径，拒绝覆盖已有数据库；周期备份同步补齐 `agent_tasks.db`，且不会轮转删除 schema 升级快照。
