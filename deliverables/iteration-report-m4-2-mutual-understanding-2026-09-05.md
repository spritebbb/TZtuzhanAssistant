# M4.2 · 双向了解与修复回归（M4 第二切片）

日期：2026-09-05  
状态：已完成（M4 退出标准全部达成）

## 本轮目标

补齐 M4 三条退出标准：冲突→修复多轮测试可重复且初识不越级；她不迎合、不把偏好当事实；用户可查看和重置自动形成的互动偏好。同时兑现"双向了解"——用户也能逐渐了解她的稳定偏好、雷区和立场。

## 交付

- 双向了解：`backend/core/her_profile.py` 把人格卡的"性格/喜好与厌恶/行为准则"结构化为五节（她的底色/她喜欢/她厌恶/她的雷区/她的立场），`GET /api/memory/her-profile` 暴露；内容运行时只读、不可被模型改写。
- 互动偏好主权：`GET/DELETE /api/memory/interaction-style` 查看与重置自动形成的说话风格提炼（users.style_profile）；共同语言支持逐条删除（`DELETE /api/memory/terms/{id}`）。
- 记忆管理页改造：新增「她记住的 / 了解她」双 tab；「了解她」内含她的侧面展示、互动偏好（说话方式 + 共同语言清单）、重置按钮与逐条删除。
- 观点连续性防线：persona notes 增加确定性注入——允许友好分歧、接受有依据的新看法并说明改变原因；不为迎合瞬间推翻稳定观点；不把偏好说成对方的客观事实。
- 冲突修复回归：`tests/test_m4_relationship.py` 覆盖多轮冲突循环（真实冒犯→张力有来源有上限→软话不清零→道歉+担责显著下降→修复到零不为负）、初识全程不越级、防线 prompt 断言、双 API 行为。
