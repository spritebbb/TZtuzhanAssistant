# Sprint 1 · 可信记忆与用户主权最小闭环（第一切片）

日期：2026-09-05  
状态：已完成

## 本轮目标

让"记得你"首先成为可信能力：每条结构化记忆可回答"从哪来、确定吗、什么时候确认过"，误记可纠正且纠正后不留残留。

## 交付

- facts schema 升至 v2：新增来源类型、来源消息 ID、0–1 置信度、验证/过期时间、固定状态与呈现策略；旧数据自动迁移为 `legacy`，升级前由 M0 快照机制备份。
- 每日事实提炼改为结构化输出，事实记录可追溯到原始消息；模型推断置信度低于 1，用户在管理页改写后自动标为一手纠正、置信度 1 并记录验证时间。
- facts schema 升至 v3：冲突事实以 `pending_confirmation` 独立落库并指向原事实；确认前不进入关键词/向量召回，也不建向量索引。
- 记忆管理页展示来源、置信度与确认日期，支持逐条切换"不主动提起"；主动消息生成读取禁提清单，用户先提及时的普通对话召回不受影响；冲突候选在管理页并列展示，由用户明确选择保留原记忆或采用新记忆。
- 新增 `backend/core/fact_lifecycle.py` 统一事实生命周期服务：SQLite 事务先落账，再同步向量；删改级联作废待确认候选；召回层按 SQLite active 状态复核向量命中，即使索引删除失败也不会残留进 prompt；存量迁移只重建仍有效的事实。

## 收尾
