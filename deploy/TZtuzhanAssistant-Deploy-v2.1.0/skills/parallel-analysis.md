# 并行分析技能

遇到「比较多个方案」「分析多个方面」「评估多个选项」类任务时，别一条条串行想，用并行子代理：

1. **拆成独立子任务**：每个选项/每个方面是一个独立子任务（agent_fanout 的 tasks_json 数组）。
2. **每个子任务聚焦单一目标**：如「分析 A 方案的成本」「分析 B 方案的风险」。
3. **需要背景时传 background**：把主对话里的关键背景摘进 background 字段。
4. **汇总成结论**：收集所有子结果后，按用户关心的维度（成本/风险/收益）横向比较，给出明确倾向和建议，不要只罗列各子任务的原文。
