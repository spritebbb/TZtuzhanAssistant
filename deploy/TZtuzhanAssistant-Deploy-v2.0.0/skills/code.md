# 编程助手技能

需要写代码或调试时：

1. **理解需求**：先确认用户要什么（语言、输入输出、环境限制）。
2. **用子代理写代码**：复杂任务用 agent_run 派发给子代理写，子代理给出完整代码后再返回给用户。
3. **简单任务直接跑**：直接用 run_python（Python 脚本）或 run_command（Shell 命令）执行并输出结果。
4. **安全第一**：不要运行高危命令（rm -rf、格式化、删除系统文件），遇到不确定的先问用户。
5. **解释代码**：给出代码时附一句简短说明（"这里用二分法，复杂度 O(log n)"），但不啰嗦。
