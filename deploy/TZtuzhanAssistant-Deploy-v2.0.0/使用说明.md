# 菟菚助手 · 一键部署包（Web 桌面版）

本包是菟菚助手（TZtuzhanAssistant）的**浏览器运行版**：不需要 Node.js，也不需要 Electron 打包环境。
后端会自动托管前端页面（http://127.0.0.1:8801），双击启动脚本即可使用。

## 一、系统要求

- Windows 10 / 11
- 已安装 **Python 3.11 ~ 3.13**（安装时勾选 “Add python.exe to PATH”）
  - 更早或过新的版本可能导致 `torch` / `sentence-transformers` 安装失败
- 可联网（首次安装依赖约 1~2 GB，之后每天正常使用流量很小）
- 现代浏览器（Chrome / Edge）

> 本包**不需要** Node.js、不需要单独安装 Electron。

## 二、首次启动

1. 解压本包到任意目录（建议英文路径，例如 `D:\Tuzhan`）。
2. 双击 **Start-Tuzhan.bat**。
3. 脚本会自动：
   - 创建 `.venv` 虚拟环境；
   - 安装 `requirements.txt` 依赖（首次较慢，请耐心等待）；
   - **初始化数据库**（在 `data/` 下创建 `bot.db`、`sessions.db`、`agent_tasks.db`，仅首次或缺失时执行，不会清空已有数据）；
   - 从 `.env.example` 生成 `.env`；
   - 若 `LLM_API_KEY` 为空，会自动用记事本打开 `.env` 让你填写；
   - 启动后端并打开浏览器页面。
4. 在 `.env` 中至少填写：

```ini
LLM_API_KEY=sk-你的真实Key
```

可选增强配置（留空则对应功能关闭）：

| 配置 | 功能 |
|---|---|
| `SEARCH_API_KEY` / `SEARCH_ENGINE` | 联网搜索（留空也可用 Bing/DuckDuckGo 兜底） |
| `IMAGE_API_KEY` / `IMAGE_BASE_URL` / `IMAGE_MODEL` | 文生图 |
| `VISION_*` | 识图（不填则复用 IMAGE key） |
| `MOOD_CITY` | 心情绑定城市天气 |

## 三、日常使用与停止

- 启动：双击 **Start-Tuzhan.bat**（后端已在运行时会直接复用并打开页面）。
- 停止：双击 **Stop-Tuzhan.bat**，或在任务栏托盘中关闭名为 `Tuzhan-backend` 的最小化窗口。
- 聊天记录、记忆、图片保存在包内 `data/` 目录，删除包前请先备份。
- 立绘、人格、技能、插件都已内置，无需额外配置。
- 手动重建/补全数据库（不会清空数据）：双击 **Init-Database.bat**。

## 四、常见问题

**1. 提示 “Python not found”**
请安装 Python 3.11~3.13 并勾选 “Add python.exe to PATH”，然后重开启动脚本。

**2. 依赖安装失败 / 超时**
脚本会提示手动执行。也可以直接使用国内镜像：

```bat
.venv\Scripts\python.exe -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

**3. 首次对话较慢 / 语义检索下载模型**
本包默认使用较小的 `BAAI/bge-small-zh-v1.5`（约 100MB）作为记忆 embedding 模型，
首次使用时会在后台下载；也可在 `.env` 中改成 `BAAI/bge-m3`（约 1.2GB，效果更好），
或设 `MEMORY_EMBED_FORCE=1` 强制使用零依赖的哈希回退。

**4. 页面打不开 / 端口被占用**
确认 8801 端口未被占用，或把占用程序关闭后重试：

```bat
netstat -ano | findstr 8801
```

**5. 局域网访问**
默认只监听本机（安全）。如需局域网访问，请阅读包内 `.env.example` 中
`AGENT_REMOTE_TOKEN` / `AGENT_ALLOWED_HOSTS` 的说明，并手动用 `--host 0.0.0.0` 启动后端。

## 五、目录结构（包内）

```text
Start-Tuzhan.bat        一键启动
Stop-Tuzhan.bat         一键停止
Init-Database.bat       手动初始化/补全数据库（幂等）
init_database.py        初始化脚本（由上述 bat 调用）
使用说明.md             本说明
.env.example            配置模板（首次启动自动复制为 .env）
backend/                后端服务（FastAPI）
frontend/dist/          已构建前端页面（无需 Node）
plugins/                工具插件
skills/                 技能目录
assets/                 立绘与素材
persona-菟菚.md          人格文件
requirements.txt        后端依赖清单
```
