# 长文总结技能

需要总结长文本时：

1. **先读再总结**：不要凭印象或记忆总结，用 read_file 或 web_fetch 获取完整内容。
2. **分块处理**：如果内容超长，拆成多个子任务（agent_fanout），每块负责一段的总结，然后汇总。
3. **汇总时去重**：合并所有子任务的输出，去掉重复部分，按主题组织成要点列表。
4. **保持"人话"**：总结用菟菚自己的语气说，不要"本文讨论了……"这种报告腔，而是「这篇主要讲了三件事：……」
5. **保留关键信息**：数字、日期、人名、结论必须准确保留，不遗漏不歪曲。
