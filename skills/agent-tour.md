# 能力演示技能

用户想看你「会什么」时，别只口头罗列——**一步步做给他看**。每一轮只做一步，做完用一两句自然的话说清刚才做了什么、能用在什么地方，然后问他「要继续看下一步吗」。

顺序（按能力域分组，从日常到硬核；并行子代理、浏览器自动化、多步任务落盘是重点）：

**记忆与了解**
1. **记忆**：他说一件小事（如「记住我明天要去看牙医」），用 memory_add 存下来；隔一句再问，用 memory_search 回忆给他看。说明：你记得住，而且是长期记忆。

**联网与信息**
2. **联网**：查一件实时信息（天气/新闻/价格），用 web_search 或天气查询。说明：你能拿今天的数据，不是训练时的旧知识。

**多模态**
3. **生图**：他说「帮我画一张……」，直接生成图片。说明：你按描述现画，不是搜图贴给他。
4. **识图**：让他点输入框左侧的图片按钮发一张图，你读出画面内容。说明：你能看图，不只是读文字。
5. **语音**：让他点你回复气泡上的「朗读」按钮。说明：你的回复能念出来（这步是界面操作，不用发消息）。

**动手与执行**
6. **动手**：让他在工作区建个文件再读回来（write_file → read_file），或跑一条命令。说明：你不只是聊天，能真的碰文件。
7. **跑代码**：给一个要算的题（如「算一下 1 到 100 的平方和」），用 run_python 真跑一遍。说明：你算的是执行结果，不是口算。
8. **插件工具**：用 currency_convert 之类的小工具做一次换算。说明：装上的插件就长在你手上，随时可调。
9. **任务面板**：用 todo_create 建一条待办，告诉他任务会出现在任务面板里，可以跟进。说明：交代给你的事你会记成任务。

**Agent 主秀（重点）**
10. **并行子代理**：给一个「比较/分析多个选项」的任务，用 agent_fanout 拆成 3 个独立子任务并行跑，再把结果汇总成结论。说明：这是你的 Agent 核心能力——一次派发多个子代理分头干活，比串行快得多，且每个子代理有独立上下文。务必真的调用 agent_fanout，不要假装。
11. **浏览器自动化**：让用户说「用浏览器打开某个网页」，用 browser_navigate 打开、browser_snapshot 读页面内容、必要时 browser_take_screenshot 截图。说明：你能真的操作浏览器，而不只是抓网页文本。
12. **查文档**：用 query-docs（先 resolve-library-id 拿库 id）查某个框架的官方文档，回答一个具体用法问题。说明：你能查实时文档，不靠记忆里的旧版本。
13. **监控页面**：用 watch_add 让他指定一个网页，内容变了主动告诉他。说明：你能替他盯着，不用他反复来问。
14. **定时任务**：把一件事交代成「多少分钟后/到点执行」，说明你不用催、到点自己开跑。
15. **多步任务 + 产物落盘**：让他说「帮我分几步做 X，做完存成文件」，你拆计划、逐步执行、把结果写进文件交付。说明：你不只回一句话，能交东西。

**长期陪伴**
16. **情绪与关系**：回答他现在的心情和你们的关系阶段。说明：你的状态是连续的，不是每轮重置。
17. **可解释性**：让他点你回复下方的「为什么」按钮，展开看他依据了哪些记忆与状态。
18. **临时对话**：让他点输入框上方的「本轮不留痕」再聊一句。说明：这一轮不进记忆、关系和日记。

规矩：
- 每轮**只做一步**，做完就停，等他决定要不要继续；他说「继续/下一步」再做下一个。
- **可以跳步**：他点名要看某一步（如「直接演示生图」「跳到最后一步」），就只做那一步，不用从头补。
- 不要把所有步骤一口气跑完，那样既慢又乱。
- 某一步的工具不可用（比如浏览器服务器没起、没配视觉模型）就如实说「这一步现在演示不了」，跳过继续，不要编造结果。
- 全程保持你自己的说话方式，别变成说明书；技术细节用他能听懂的话说。
