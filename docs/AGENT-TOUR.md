# 菟菚能力演示（Agent 教程）

> 2026-09-09 用户要求：给菟菚内置一套新手教程式演示流程，重点展现 **Agent 能力**。
> 执行：ZCode。演示脚本是产品内置的（技能 + 结构化脚本 + 前端面板），不是文档。
> 同日扩充：9 步 → 18 步，按能力域分组，补齐多模态与长期陪伴；界面型步骤标 `kind="ui"`。

## 两种触发方式

1. **聊天里说一句**：「新手教程」「演示一下」「带我看看你会什么」
   → 命中内置技能 `skills/agent-tour.md`，菟菚按顺序**逐步真实执行**，每步做完停下等你决定是否继续；
   也可以**点名跳步**（「直接演示生图」「跳到最后一步」）。
2. **点界面入口**：顶部「更多」→「**能力演示**」
   → 打开演示清单（`GET /api/tour`），按分组展示；`chat` 型步骤点「发这句」直接填进输入框，
   `ui` 型步骤标「界面操作」，照说明点对应按钮即可。

## 演示顺序（18 步，按能力域分组）

| # | 分组 | 步骤 | 建议原话 / 操作 | 验收点 |
|---|---|---|---|---|
| 1 | 记忆与了解 | 长期记忆 | 记住一件事：我明天要去看牙医。 | 追问「我明天要干嘛」能准确答出 |
| 2 | 联网与信息 | 联网查实时信息 | 查一下今天武汉的天气。 | 回答带当天真实温度 |
| 3 | 多模态 | 生图 | 帮我画一张猫趴在窗台上晒太阳的图。 | 气泡下方出现新生成的图片 |
| 4 | 多模态 | 识图 | 点输入框左侧图片按钮上传一张图，问她看到了什么 | 描述的是图里真实内容 |
| 5 | 多模态 | 语音朗读 | 点她回复气泡上的「朗读」按钮 | 浏览器播放语音，再点可停 |
| 6 | 动手与执行 | 动手操作本机 | 在工作区建 demo.txt 写上今天日期再读回来 | 工作区出现该文件且她念得出内容 |
| 7 | 动手与执行 | 跑代码 | 跑个脚本算一下 1 到 100 的平方和。 | 出现 `run_python`，答案 338350 |
| 8 | 动手与执行 | 汇率换算 | 把 100 美元换算成人民币。 | 给出金额并说明所用汇率 |
| 9 | 动手与执行 | 任务面板 | 帮我建个待办：本周内整理一份 Agent 演示清单。 | 任务面板出现该待办 |
| 10 | **Agent 主秀** | **并行子代理** | 帮我比较 Python 和 Node.js 做后端，从性能、生态、学习成本三个方面分析。 | 出现 `agent_fanout`，结论按三维度横向比较 |
| 11 | **Agent 主秀** | **浏览器自动化（MCP）** | 用浏览器打开 example.com，看看页面上写了什么。 | 弹出浏览器，她答出「Example Domain」 |
| 12 | Agent 主秀 | 查实时文档（MCP） | 帮我查一下 fastapi 的文档，怎么定义一个带查询参数的路由？ | 给出可运行示例并引用来源 |
| 13 | Agent 主秀 | 监控页面 | 帮我盯着 https://example.com 这个页面，有变化告诉我。 | `watch_list` 里有该地址，变化后主动开口 |
| 14 | Agent 主秀 | 定时任务 | 帮我分几步整理这周的会议纪要，30 分钟后执行。 | 任务面板出现「已定时」任务，到点开跑 |
| 15 | **Agent 主秀** | **多步任务 + 产物落盘** | 帮我分几步整理一份「本周 Agent 演示清单」，做完把结果存成文件。 | 任务面板出现多步计划；`workspace/agent-reports/` 有产物 |
| 16 | 长期陪伴 | 情绪与关系状态 | 你现在心情怎么样？我们认识多久了？ | 回答带当前心情与关系阶段 |
| 17 | 长期陪伴 | 可解释性 | 点她回复下方的「为什么」按钮 | 展开依据面板，列出参考的记忆/状态 |
| 18 | 长期陪伴 | 临时对话（不留痕） | 点输入框上方「本轮不留痕」再聊一句 | 气泡出现「不留痕」标记，刷新后消失 |

第 10、11、15 步是主秀；第 4、5、17、18 步是**界面操作**（不用发消息）。

## 演示前的检查清单

```bat
:: 1. 起 MCP 桥（第 11、12 步需要；不跑这两步可跳过）
scripts\start-mcp-playwright.bat

:: 2. 起菟菚
start.bat
```

- 后端启动日志里应出现 `[MCP] 已恢复外部服务器: playwright` 与 `context7`；
- 设置页 → MCP 服务器：playwright 24 个工具、context7 2 个工具；
- 演示模式（`.env` 的 `AGENT_DEMO_MODE=1`）**开着**时工具不弹确认，演示更顺；
  演示完记得改回 `0`。

## 机制说明（为什么每步都能真跑）

- **技能点名工具 → 打开工具通道**：`agent-tour.md` 正文里点名了 `agent_fanout`、
  `write_file`、`web_search`、`run_python`、`currency_convert` 等，pipeline 的
  `skills_reference_tools` 检测到后，这一轮就给模型工具 schema（否则指令只能落在
  纯流式轮次里「嘴上照做」）。
- **MCP 工具按需注入**：技能正文提到 `browser_navigate` / `query-docs`，
  按需注入即暴露对应服务器的工具；不需要常驻。
- **非工具能力也有确定性入口**：生图走意图路由 `need_draw`，跑代码/汇率走工具循环关键词，
  多步任务走派活识别 `detect_dispatch_request`——这些在 `tests/test_demo_tour.py` 里逐条断言，
  脚本改动若让某步失去触发路径，测试会红。
- **每步一句原话**：`backend/core/demo_tour.py` 的 `TOUR_STEPS` 是唯一数据源，
  `/api/tour` 与前端面板都从它渲染，测试也校验它。

## 如果某一步没效果

| 现象 | 原因 | 处理 |
|---|---|---|
| 第 3 步没出图 | 没配生图端点 | 设置页填 `IMAGE_BASE_URL` / `IMAGE_MODEL` / `IMAGE_API_KEY` |
| 第 4 步识图没效果 | 没配视觉模型 | 设置页填 `VISION_*`，或复用生图端点 |
| 第 5 步朗读没声音 | TTS 未就绪或浏览器拦截音频 | 确认后端 `/api/tts` 可用；点一次页面再试（浏览器自动播放策略） |
| 第 7/8 步没调工具 | 本轮没走工具循环 | 再说一次「跑个脚本…」/「换算一下…」，或确认不是临时对话 |
| 第 10 步没出现 `agent_fanout` | 本轮没走工具循环 | 再说一次「用并行子代理比较…」，或确认不是临时对话 |
| 第 11 步没弹浏览器 | MCP 桥没起 | 跑 `scripts\start-mcp-playwright.bat`，确认打印「已连接（Streamable HTTP）」 |
| 第 11 步提示找不到 Chrome | Playwright 默认找系统 Chrome | 桥已带 `--browser chromium`；若要 Chrome 请先装 |
| 第 12 步查不到文档 | 网络/代理问题 | 该步可跳过，其余能力不受影响 |
| 第 15 步没有产物文件 | 任务未执行完或没落盘 | 去任务面板看执行状态；产物在 `workspace/agent-reports/` |
| 每步都要点确认 | 演示模式没开 | `.env` 设 `AGENT_DEMO_MODE=1` 并重启后端 |
