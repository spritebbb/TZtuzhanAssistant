# 菟菚能力演示（Agent 教程）

> 2026-09-09 用户要求：给菟菚内置一套新手教程式演示流程，重点展现 **Agent 能力**。
> 执行：ZCode。演示脚本是产品内置的（技能 + 结构化脚本 + 前端面板），不是文档。

## 两种触发方式

1. **聊天里说一句**：「新手教程」「演示一下」「带我看看你会什么」
   → 命中内置技能 `skills/agent-tour.md`，菟菚按顺序**逐步真实执行**，每步做完停下等你决定是否继续。
2. **点界面入口**：顶部「更多」→「**能力演示**」
   → 打开演示清单（`GET /api/tour`），每步一句原话，点「发这句」直接填进输入框，回车发送。

## 演示顺序（7 步，从日常到硬核）

| # | 步骤 | 展示什么 | 建议原话 | 验收点 |
|---|---|---|---|---|
| 1 | 长期记忆 | 说记住就真的记得住 | 记住一件事：我明天要去看牙医。 | 追问「我明天要干嘛」能准确答出 |
| 2 | 联网查实时信息 | 拿的是今天的数据 | 查一下今天武汉的天气。 | 回答带当天真实温度 |
| 3 | 动手操作本机 | 能真读写文件 | 在工作区建 demo.txt 写上今天日期再读回来 | 工作区出现该文件且她念得出内容 |
| 4 | **并行子代理（Agent 核心）** | 一次派发多个子代理分头干活 | 帮我比较 Python 和 Node.js 做后端，从性能、生态、学习成本三个方面分析。 | 工具面板出现 `agent_fanout`，结论按三个维度横向比较 |
| 5 | **浏览器自动化（MCP）** | 真的开浏览器读页面 | 用浏览器打开 example.com，看看页面上写了什么。 | 弹出浏览器窗口，她答出「Example Domain」 |
| 6 | 查实时文档（MCP） | 查官方文档不靠旧记忆 | 帮我查一下 fastapi 的文档，怎么定义一个带查询参数的路由？ | 给出可运行示例 |
| 7 | 任务面板 | 交代的事变成可跟进任务 | 帮我建个待办：本周内整理一份 Agent 演示清单。 | 任务面板出现该待办 |

第 4、5 步是主秀；前 3 步负责让人先建立「她真能干活」的直觉。

## 演示前的检查清单

```bat
:: 1. 起 MCP 桥（第 5、6 步需要；不跑这两步可跳过）
scripts\start-mcp-playwright.bat

:: 2. 起菟菚
start.bat
```

- 后端启动日志里应出现 `[MCP] 已恢复外部服务器: playwright` 与 `context7`；
- 设置页 → MCP 服务器：playwright 24 个工具、context7 2 个工具；
- 演示模式（`.env` 的 `AGENT_DEMO_MODE=1`）**开着**时工具不弹确认，演示更顺；
  演示完记得改回 `0`。

## 机制说明（为什么每步都能真跑）

- **技能点名工具 → 打开工具通道**：`agent-tour.md` 正文里点名了 `agent_fanout`、
  `write_file`、`web_search` 等，pipeline 的 `skills_reference_tools` 检测到后，
  这一轮就给模型工具 schema（否则指令只能落在纯流式轮次里「嘴上照做」）。
- **MCP 工具按需注入**：技能正文提到 `browser_navigate` / `query-docs`，
  按需注入即暴露对应服务器的工具；不需要常驻。
- **每步一句原话**：`backend/core/demo_tour.py` 的 `TOUR_STEPS` 是唯一数据源，
  `/api/tour` 与前端面板都从它渲染，测试也校验它。

## 如果某一步没效果

| 现象 | 原因 | 处理 |
|---|---|---|
| 第 4 步没出现 `agent_fanout` | 本轮没走工具循环 | 再说一次「用并行子代理比较…」，或确认不是临时对话 |
| 第 5 步没弹浏览器 | MCP 桥没起 | 跑 `scripts\start-mcp-playwright.bat`，确认打印「已连接（Streamable HTTP）」 |
| 第 5 步提示找不到 Chrome | Playwright 默认找系统 Chrome | 桥已带 `--browser chromium`；若要 Chrome 请先装 |
| 第 6 步查不到文档 | 网络/代理问题 | 该步可跳过，其余能力不受影响 |
| 每步都要点确认 | 演示模式没开 | `.env` 设 `AGENT_DEMO_MODE=1` 并重启后端 |
