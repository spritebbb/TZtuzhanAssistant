## 总判断

菟菚现在「会聊、会记、会主动、会养成」。下一阶段的空白主要在三个方向：

1. **感知世界**——她的主动目前只基于"时间"（你多久没来），不基于"事件"（世界发生了什么）。
2. **走出窗口**——她只存在于聊天窗里，桌面上没有她的"存在形态"。
3. **听见声音**——A1 让她会说了，但语音链路只有单程（她说你听），你仍在打字。

## 绿区 · 建议下一轮先做（低成本 × 高冲击）

### N1. 世界感知主动性（事件驱动的主动消息）

- **现状**：initiative 引擎（A3 收尾后）已有完整额度/冷却/占位机制；触发源只有闲置时长。天气、联网搜索工具链齐备。
- **改动**：新增事件源层——
  - 天气突变（降温/暴雨预警）→ 她提醒加衣带伞；
  - 节日临近（对接 important_dates 之外的公共节日）→ 提前念叨；
  - 可选：订阅话题的新闻（RSS/搜索）→ 她主动吐槽"你关注的那个事有新进展"。
  - 全部走既有每日主动额度与冷却，不新增打扰。
- **成本**：1-2 天。**收益**：让"她活在你的世界里"，而不是"活在你的聊天记录里"。
- **风险**：事件质量门控要严（宁缺勿滥），否则退化成推送垃圾；B3 eval 需补场景红线。

### N2. 周年纪念叙事（里程碑回顾）

- **现状**：C5 已沉淀 mood_log / affection_log / 聊天热力全部历史数据；D4 纪念册导出管线可复用。
- **改动**：相识 30/100/365 天等里程碑，daily 批处理自动生成「我们这一路」回顾叙事（关键节点 + 数据梗概 + 她的口吻），可一键导出纪念册长图。
- **成本**：约 1 天（数据零新增，纯编排）。**收益**：情感产品经典杀器，用户会反复看。
- **风险**：里程碑日期探测别漏别重（kv 记账防重发）；文案须过人格红线。

### N3. 记忆图谱可视化（「她眼中的你」）

- **现状**：triples/facts 结构化记忆完整，C7 已有记忆管理页（列表形态）。
- **改动**：新增图谱页——把三元组渲染成以"你"为中心的关系图（喜好/习惯/重要的人/共同的梗），节点可点入编辑/忘掉（复用 C7 删改 API）。
- **成本**：1-2 天（前端图可视化是主要工作）。**收益**：记忆透明化 → 信任建设；同时是 C7 管理页的视觉升级。
- **风险**：图谱规模增长后的布局性能；敏感记忆的展示分寸。

## 蓝区 · 中期或有前置

### N4. 语音输入闭环（STT）

- **现状**：A1 TTS 完成（她说你听），输入仍纯打字。
- **改动**：输入栏加语音按钮，本地 whisper 或 API 转写后进 pipeline；与自动朗读组合出"打电话"模式。
- **成本**：1-2 天。**收益**：拟人感第二级跃升（第一级是 TTS）。
- **风险**：本地 whisper 的模型体积与 CPU 延迟；转写噪声进记忆系统的污染（需置信度门控）。

### N5. 桌面宠物模式

- **现状**：B4 五档心情立绘 + 关系距离 + 呼吸/雀跃动效已全部就绪；Electron 主进程在手。
- **改动**：无边框透明悬浮小窗，立绘常驻桌面角落，随 `/api/meta` 实时换状态；点击展开快捷对话，可拖拽、可收起。
- **成本**：2-3 天（主要在 Electron 窗口与交互设计）。**收益**：「存在感」的形态升级——不用打开聊天窗她也"在"。个人最期待项。
- **风险**：透明窗在 Windows 多 DPI/多显示器下的边界 case；勿扰场景（全屏游戏/演示）的自动避让。

### D3. 共同活动（路线图原定剩余项）

- 共享 todo、一起读文聊感想、你画我猜。工具链齐备，纯玩法封装。成本 3 天+，视玩法选型。

### D8. 移动端推送（路线图原定剩余项）

- PWA + Web Push。**前置**：先按 `docs/DEPLOYMENT-OPTIONS.md` 拍板公网方案（Tailscale / Cloudflare Tunnel / Caddy），推送需 HTTPS 可达域名。约 5 天。

### N6. 工程健康：E2E 测试设施 + CI

- **现状**：54 个测试全是脚本级，真实 UI 链路零覆盖（A4 已挂账）；功能越多回归风险越大。
- **改动**：Playwright 最小 E2E 套件（发消息/收到回复/立绘切换/面板开合）+ 提交前自动跑。
- **成本**：1-2 天起步，之后持续维护。**收益**：护住全部迭代成果的工程护栏（B3 护人格，这个护链路）。

## 第二批候选（2026-09-04 补充，更偏"持续运转的生命"向）

### 情感与关系深化

#### N7. 她的日常节奏（独处自转）
- **现状**：B1 离线叙事是"事后讲述"（你回来她讲做了什么）；她的时间是静止的，只在对话时存在。
- **改动**：给她一张研究院作息表（上午做实验/下午咖啡时间/深夜看论文），当前时段影响她的状态、口吻与主动内容——你下午找她，她可能"刚泡好咖啡"。从"事后讲"升级为"当下在"。
- **成本**：1-2 天。**收益**：时间在她身上连续流逝的最后一公里。**风险**：作息与 B1/C3/C6 事件源的优先级仲裁。

#### N8. 随机日常事件系统
- **改动**：每日抽签式小事件（"今天打翻了咖啡"/"实验数据终于跑通了"/"读到一篇好论文"），注入行为帧成为她当日的谈资与心情来源。
- **成本**：约 1 天。**收益**：日常有波澜，打开就有新话题。**风险**：事件池需要持续维护，否则重复感反噬。

#### N9. 冲突与和解剧情
- **现状**：C1 哄好机制已在（tension/repair_tension），但只响应用户触发。
- **改动**：偶发剧情化误会事件（需极高门槛：亲密以上、低频、可拒绝），和解后触发羁绊彩蛋。
- **成本**：1-2 天。**收益**：关系深度的戏剧化表达。**风险**：频率/分寸失控就是灾难，必须先过 B3 eval 红线。

### 关怀与责任

#### N10. 用户情绪长期曲线（她眼中的你·心情版）
- **现状**：D6 深夜守护是"即时接住"；perception 已有情绪感知。
- **改动**：她默默记录你的情绪趋势（dashboard 加一条"你的心情（她记的）"曲线），持续低落数日时她主动认真关心一次（非毒舌）。
- **成本**：1-2 天。**收益**：「在乎你」的最深形态。**风险**：敏感功能，需明显开关与克制触发；误判的打扰成本很高。

### 感官与内容

#### N11. TTS 情绪声线
- **现状**：A1 朗读是固定音色参数；edge-tts 支持 rate/pitch 调整。
- **改动**：朗读参数随心情档位微调（开心语速快一点、低落慢一点轻一点）。
- **成本**：半天。**收益**：声音人格化，便宜大碗。

#### N12. 节气/季节限定内容
- **改动**：二十四节气彩蛋问候 + 立绘季节差分（围巾版/短袖版）。
- **成本**：问候 1 天，立绘视美术。**收益**：时间仪式感的共鸣点。

#### N13. 她的小课堂（知识反刍）
- **现状**：D2 书架她会"引用"；C2 研究课题是"观察你"。
- **改动**：反向版——她定期从你投喂的书里挑一段，以她的视角讲给你听（"你上次给我的那本书，我看到一个有意思的地方"）。
- **成本**：约 1 天。**收益**：书架从"工具"变"共同话题"，研究员人设的完整闭环。

### 渠道与生态

#### N14. IM 渠道接入
- **改动**：接入微信/Telegram bot，随时随地聊（复用后端会话与 pipeline）。
- **前置**：同 D8 公网部署。**成本**：2-3 天。**收益**：陪伴半径从桌面扩展到全天。

#### N15. 数据主权包
- **改动**：一键导出她的全部记忆与聊天记录 / 彻底删除 / 数据库本地加密选项。
- **成本**：约 1 天。**收益**：情感产品的信任地基，越深情越需要"你能掌控"。

### 底层体验

#### N16. 响应速度与离线兜底
- **改动**：首字延迟优化（prompt 瘦身/流式首包）、本地小模型离线兜底（断网时她仍能回简单的话，明示"我现在脑子不太灵光"）。
- **成本**：1-2 天。**收益**：日常体验的隐形基石。
