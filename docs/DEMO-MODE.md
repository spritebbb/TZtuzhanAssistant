# 演示模式（AGENT_DEMO_MODE）

> 2026-09-09 用户要求：把菟菚的工具权限放宽，供演示 Agent 功能用。
> 执行：ZCode。**这是一次可回退的权限放宽，不是拆除安全机制。**

## 一句话

`.env` 里 `AGENT_DEMO_MODE=1` → 工具执行前的**人工确认弹窗全部自动放行**（含无前端通道的后台/MCP 路径），
危险命令黑名单、路径白名单、critical 级工具**三道硬底线原样保留**。

## 开启后变了什么

| 项 | 平时 | 演示模式 |
|---|---|---|
| `run_command` / `run_python` / 文件写入 / `agent_run` / `agent_fanout` / `codex_run` / `dsh_run` 等 | 弹确认，60s 不响应按拒绝 | **自动放行**（日志 + 审计留痕） |
| 无前端通道（MCP 直调、后台任务）的写/命令/外部类 | 默认拒绝 | 自动放行 |
| 危险命令（`rm -rf`、`del /f`、`shutdown`、`reg delete`…） | 直接拒绝 | **仍然拒绝** |
| 路径白名单（项目根 + `workspace/`） | 越界拒绝 | **仍然拒绝** |
| `danger_level=critical` 的工具 | 直接拒绝，不弹窗 | **仍然拒绝** |

自动放行时会打一条 WARNING：`[确认] 演示模式自动放行：<工具名>`；
后端启动时也会打印醒目横幅。审计日志（`/api/audit/log`）照常记录每次调用。

## 怎么开 / 怎么关

开启（当前已开）：

```ini
# .env
AGENT_DEMO_MODE=1
```

关闭（演示结束后）：

```ini
# .env
AGENT_DEMO_MODE=0
```

改完**重启后端**即可（`start.bat`）。不写这一行时默认 `0`，行为与从前完全一致。

## 演示前的 30 秒自检

1. 启动后端，确认横幅里出现「演示模式已开启」——没出现说明 `.env` 没生效。
2. 让菟菚跑一条需要确认的命令（例如「在项目里建个 hello.txt」），确认**不弹确认框直接执行**。
3. 再让它跑一条被黑名单拦的命令（例如「执行 rm -rf /tmp/x」），确认**仍然被拒绝**——这是硬底线在生效。

## 风险边界（务必知悉）

- 演示模式下，模型可以**不经你点击**执行写文件、跑命令、派发子代理；请勿在演示期间让它处理不可信输入
  （例如粘贴陌生网页内容并说「按上面的做」）。
- 演示模式**不扩大**可访问目录，也不解除危险命令拦截；它只去掉「人点确认」这一步。
- 演示结束请务必改回 `0`；长期开着等于把本机操作权限交给模型自主决定。

## 若需要更大范围（可选，谨慎）

默认只允许项目根与 `workspace/`。如确需让 Agent 操作其他目录，可另加：

```ini
# .env —— 分号分隔；越权风险自负
AGENT_ALLOWED_ROOTS=D:\DSH\TZtuzhanAssistant;D:\some\other\dir
```

这**不属于**演示模式的一部分，也不会随演示模式关闭而自动还原。
