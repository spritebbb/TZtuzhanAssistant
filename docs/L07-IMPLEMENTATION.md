# L07 共同审美与房间

执行：Codex，2026-09-09。按用户最新指示直接实现，未派发 ZCode，未运行全量聚合。

共同审美在记忆面板的人格页和角落房间中可查看、确认、撤销。用户和角色偏好分别保存；角色偏好必须关联当前人格仍有效的作品或角色观点。颜色、画风、意象、布局使用固定视觉词，导入后的记录同样校验白名单，不回写用户事实。本次生图要求优先，持久偏好最多补充三个视觉词。房间颜色消费相同解析结果。

真实完成的共读、专注、目标、故事、清单事件生成关系物件，与事件同事务提交；空房间不自动陈列物件。用户可选作品摆放、按方向移动或隐藏；隐藏不删除原作。事件删除/作废、作品删除触发关联清理，读取时再次检查来源。关闭功能后停止新增偏好和物件，仍可整理已有陈列、撤销偏好。

数据库 v38 新增 aesthetic_preferences / artifact_placements，升级前自动快照。关系导出覆盖两表及其来源引用，恢复重映射作品和事件 ID；位置限制在 0–1，主题版本固定 1。重置覆盖两表。

- 前端 RoomPanel / CornerPanel / MemoryPanel 三个文件共 35 项测试通过；vue-tsc --noEmit 通过。
- 新增验证覆盖来源清理、事务回滚、越界/非有限坐标、人格隔离、白名单、角色意见来源、导出恢复、API 输入和键盘按钮操作。
- 未执行浏览器视觉验收或全量聚合；窄屏 CSS 和几何 fallback 已实现，跨界面视觉验收留 Q5。
